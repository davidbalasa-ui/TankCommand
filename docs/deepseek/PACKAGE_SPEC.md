You are implementing the foundation of a mobile 3D real-time strategy game (a rebuild of a 1998 RTS).
The game will ship as an Android app on Google Play, built as a static web app and wrapped with Capacitor.
The same build also runs in desktop browsers.

This package is **infrastructure only**. You are NOT writing gameplay rules, unit stats, AI, pathfinding,
combat or missions. Gameplay numbers are unknown yet; anything that holds gameplay data uses clearly
marked placeholder values.

Read the whole spec before writing anything. Every acceptance test (IDs like `ASSET-03`) must exist as an
automated test that would FAIL if the feature were faked or stubbed.

## 2. Simulation shell (`src/sim/`)

Only the deterministic plumbing. No game rules.

### 2.1 `rng.ts` — seeded RNG
- `class Rng` using mulberry32. `constructor(seed: number)`, `nextU32(): number`, `next(): number` in [0,1),
  `int(minInclusive, maxExclusive)`, `getState(): number`, `setState(s: number)`.
- Pure, no globals.

### 2.2 `commands.ts` — command channel types
- A discriminated union `Command` with exactly these placeholder kinds for now:
  `{ kind: 'noop' }`, `{ kind: 'debug.addCounter', amount: number }`.
  Every command also carries `tick: number` and `issuer: PlayerId` (`type PlayerId = number`).
- `function validateCommand(x: unknown): Command | null` using zod; rejects unknown kinds, non-integer ticks,
  non-finite numbers.

### 2.3 `world.ts` — state container
- `interface WorldState { tick: number; seed: number; rngState: number; counter: number }`
  (`counter` is a placeholder used only to prove determinism and save/load).
- `createWorld(seed: number): WorldState`
- `step(world: WorldState, commands: readonly Command[]): WorldState` — returns a NEW object (no mutation of
  input), increments `tick`, applies `debug.addCounter` commands whose `tick` equals the current tick
  (others ignored), then advances the RNG once and adds `rng.int(0, 3)` to `counter`.
- `snapshot(world): Readonly<WorldState>` deep-frozen copy.
- `hashWorld(world): string` — stable FNV-1a 32-bit hex hash over a canonical JSON (sorted keys).

### 2.4 `loop.ts` — fixed-timestep driver
- `class FixedStepLoop` with `constructor(opts: { tickHz: number; maxStepsPerFrame: number; step: () => void })`.
- `advance(elapsedMs: number): { steps: number; alpha: number }` — accumulator pattern. Runs `step()`
  `floor(accumulated / tickMs)` times, capped at `maxStepsPerFrame` (excess accumulated time is dropped, not
  carried forever). `alpha` = leftover / tickMs in [0,1) for render interpolation.
- Negative or NaN `elapsedMs` is treated as 0.
- The loop does not read any clock itself; the caller passes elapsed time.
- Default tick rate constant `SIM_TICK_HZ = 20` exported from `src/sim/constants.ts`.

**Acceptance**
- `SIM-01` Same seed and same command list → identical `hashWorld` after 10,000 steps, across two independent runs.
- `SIM-02` Different seeds → different hashes after 100 steps.
- `SIM-03` `step` does not mutate its input (deep-equal check of input before/after, and frozen input does not throw).
- `SIM-04` `debug.addCounter` applied only on its tick; a command for a past tick is ignored.
- `SIM-05` `validateCommand` rejects: unknown kind, `tick: 1.5`, `amount: Infinity`, missing `issuer`, `null`.
- `SIM-06` `FixedStepLoop`: 20 Hz, advance(125) → 2 steps, alpha 0.5; advance(10_000) with maxStepsPerFrame 5 → exactly 5 steps; advance(-5) and advance(NaN) → 0 steps.
- `SIM-07` `Rng` with same seed yields identical first 1,000 values; `getState`/`setState` resumes the exact sequence; `int(0,3)` never returns 3 over 100,000 draws.

## 3. Asset containers (`src/assets/`, `public/assets/manifest.json`)

### 3.1 Manifest schema (zod, in `src/assets/manifestSchema.ts`)

```ts
type AssetKind = 'model' | 'texture' | 'audio';
type License = 'CC0' | 'CC-BY-4.0' | 'CC-BY-3.0' | 'ORIGINAL'; // ORIGINAL = made for this project
interface AssetEntry {
  id: string;            // /^[a-z0-9]+(\.[a-z0-9_]+)+$/  e.g. "unit.human.poc_tank"
  kind: AssetKind;
  path: string;          // relative to public/, must start with "assets/", no "..", no leading "/"
  bytes: number;         // exact file size, integer > 0
  faction?: 'human' | 'alien' | 'neutral';
  lod?: { level: 0 | 1 | 2; of: string }; // optional: this entry is an LOD of asset `of`
  tags?: string[];
  credit: {
    license: License;
    author: string;      // non-empty
    title: string;       // non-empty
    source?: string;     // https URL, REQUIRED when license is CC-BY-*
    usedFor: string;     // where it's used in game, non-empty
  };
}
interface AssetManifest { version: 1; assets: AssetEntry[] }
```

Validation also rejects (with a message naming the offending id): duplicate ids, duplicate paths,
any license string not in the enum (so `CC-BY-NC-4.0`, `CC-BY-ND-4.0`, `unknown` all fail), CC-BY without `source`,
an `lod.of` that points to a missing id or to itself, `path` with `..` or absolute paths.

### 3.2 The real manifest
`public/assets/manifest.json` contains exactly one entry today:
```json
{ "id": "unit.human.poc_tank", "kind": "model", "path": "assets/models/human/poc_tank.glb",
  "bytes": 111064, "faction": "human", "tags": ["poc"],
  "credit": { "license": "ORIGINAL", "author": "TankCommand project (scripted Blender)",
              "title": "Proof-of-concept tank", "usedFor": "Placeholder human tank" } }
```

### 3.3 Registry and loader
- `src/assets/registry.ts`: `class AssetRegistry` built from a validated manifest. `get(id)` throws a typed
  `UnknownAssetError` for unknown ids; `list(filter?: {kind?, faction?, tag?})`; `lodsOf(id)` returns LOD entries
  sorted by level.
- `src/assets/loader.ts`: `class AssetLoader`. Constructor takes `{ registry, fetchBytes: (url) => Promise<ArrayBuffer>,
  decoders: { model: (buf, entry) => Promise<T>, texture: ..., audio: ... }, baseUrl: string }` — all I/O injected so
  it is unit-testable in Node.
  - `load(id)` → Promise of decoded asset. Concurrent `load(id)` calls for the same id share ONE fetch (dedupe).
  - Cached after first success. `release(id)` decrements a refcount; at zero the entry is evicted and the optional
    `dispose(asset)` hook is called once.
  - A failed load is NOT cached: the promise rejects with `AssetLoadError` (holds id + cause), and a later `load` retries.
  - `preload(ids, onProgress?)` loads in parallel, calls `onProgress({loaded, total, id})` after each, resolves when all done,
    rejects with an `AggregateError` listing every failed id but still finishes the others.
  - Byte check: if the fetched buffer length ≠ `entry.bytes`, reject with `AssetLoadError` (catches truncated files).
- `src/assets/threeDecoders.ts` (browser only): model decoder using `GLTFLoader.parse` from
  `three/examples/jsm/loaders/GLTFLoader.js`; texture decoder via `createImageBitmap` + `THREE.Texture`; audio decoder
  returns the raw ArrayBuffer (decoding is a later package). Also `fallbackModel()` returning a magenta box mesh, which
  the renderer uses when a model fails.

### 3.4 Credits
- `scripts/credits.mjs` (plain Node, no TS build needed; may import the JSON directly and re-implement minimal checks,
  or use `tsx`-free approach — do NOT add tsx; prefer reading `public/assets/manifest.json` and writing markdown).
- Generates `CREDITS.md`: a heading, a short sentence, then a table `| Asset | Author | Licence | Source | Used for |`
  sorted by id. `--check` mode exits 1 with a diff-style message if the file is stale.
- Commit the generated `CREDITS.md`.

**Acceptance**
- `ASSET-01` The real `public/assets/manifest.json` validates.
- `ASSET-02` Each rejection case in 3.1 has its own test case and the error message contains the offending id.
- `ASSET-03` Every manifest entry's file exists on disk under `public/` and its size equals `bytes` (Node test reading the real files).
- `ASSET-04` Loader dedupes concurrent loads (fetch spy called once for 5 concurrent `load` calls).
- `ASSET-05` Failed load is not cached; a retry after the failure calls fetch again and can succeed.
- `ASSET-06` Refcount: two loads + one release keeps it cached; second release evicts and calls `dispose` exactly once.
- `ASSET-07` `preload` reports progress for each id, total correct, and rejects with all failed ids listed while the successful ones are cached.
- `ASSET-08` Size mismatch rejects with `AssetLoadError`.
- `ASSET-09` `credits:check` passes on the committed files; a test also proves it FAILS when a manifest entry is added in a temp copy (run the script with paths passed as args/env so the test can point it at a temp dir).
- `ASSET-10` (e2e) In the browser, the real `poc_tank.glb` is loaded through the registry/loader/GLTF decoder and added to the scene: test hook reports `render.loadedModels` contains `unit.human.poc_tank` and the mesh count in the scene is > 1.

## 5. Platform services (`src/platform/`)

### 5.1 Key-value storage abstraction
- `interface KvStore { get(key): Promise<string|null>; set(key, value): Promise<void>; remove(key): Promise<void>; keys(): Promise<string[]> }`
- `MemoryKvStore` (for tests), `WebKvStore` (localStorage, catches quota errors and throws `StorageFullError`),
  `NativeKvStore` — saves (large) go to `@capacitor/filesystem` under `Directory.Data`, path `saves/<key>.json`;
  small settings use `@capacitor/preferences`. A factory `createKvStore()` picks Native when
  `Capacitor.isNativePlatform()` else Web. Native store is not unit tested beyond construction with mocked plugins.

### 5.2 Save envelope (`src/platform/saves.ts`)
- `encodeSave(world: WorldState, meta: { gameVersion: string; savedAtIso: string }) → string` JSON:
  `{ format: 'tcsave', schema: 1, gameVersion, savedAtIso, checksum, payload }` where `checksum` = FNV-1a hex of
  the canonical payload JSON.
- `decodeSave(text) → { ok: true, world, meta } | { ok: false, reason: 'corrupt' | 'checksum' | 'incompatible' | 'not-a-save' }`.
  Never throws. `schema` greater than the current → `incompatible`. A migrations table `migrations: Record<number, (p) => p>`
  exists (empty today) and is applied for older schemas.
- `SaveManager(kv, opts)`: `save(slot, world)`, `load(slot)`, `listSlots()`, `autosave(world)` writing to rotating slots
  `auto-0..auto-2` (oldest overwritten), `latestAutosave()`. Total stored bytes are tracked; `save` rejects with
  `StorageFullError` if a write would exceed `opts.maxBytes` (default 5 MB).

**Acceptance**
- `SAVE-01` Round trip: save a world after 500 steps, load it, continue 500 more steps; hash equals an uninterrupted 1,000-step run.
- `SAVE-02` `decodeSave` on: random bytes, truncated JSON, valid JSON with flipped payload byte (checksum), `schema: 999`, `{}` — returns each correct reason, never throws (also a 1,000-case fuzz over random strings).
- `SAVE-03` Autosave rotation: 5 autosaves → exactly 3 auto slots kept, `latestAutosave` is the 5th.
- `SAVE-04` Exceeding `maxBytes` rejects with `StorageFullError` and leaves previous saves intact.
- `SAVE-05` `WebKvStore` maps a thrown `QuotaExceededError` DOMException-like error to `StorageFullError` (mock localStorage).

### 5.3 App lifecycle (`src/platform/lifecycle.ts`)
- `class Lifecycle` with an injected event source (so it is testable): emits `'pause'` on: document `visibilitychange`
  to hidden, Capacitor `App` `pause` event, and Android back button (`backButton`). Emits `'resume'` on visible / `resume`.
  Back button additionally emits `'back'`. Deduplicates: two pause signals in a row produce one `'pause'`.
- `bindLifecycleToBrowserAndCapacitor()` wires the real sources; guarded so it works on web without Capacitor native.

**Acceptance**
- `LIFE-01` hidden → pause; visible → resume; double hidden → single pause; back → pause + back.

### 5.4 Watchdog (`src/platform/watchdog.ts`)
- `class Watchdog({ now: () => number, freezeMs = 2000, recoverMs = 5000, onFreeze(report), onRecover(report) })`.
- `beat(channel: 'sim' | 'render')`, `setSuspended(bool)` (paused/backgrounded → no freeze detection),
  `check()` called by a timer: if any channel's last beat is older than `freezeMs`, call `onFreeze` once per freeze episode
  with `{ channel, stalledMs, lastBeats }`; if older than `recoverMs`, call `onRecover` once per episode. A new beat ends the episode.
- `installGlobalErrorCapture(target: { addEventListener }, onError)` captures `error` and `unhandledrejection`
  into `{ message, stack?, kind }`.
- The recovery UI itself is a screen (see §6) showing three buttons: Resume, Load autosave, Send bug report & return to menu.
  The buttons only emit events in this package.

**Acceptance**
- `WD-01` Using a fake clock: no beat for 2,001 ms → exactly one onFreeze; still none at 4,999 ms → no onRecover; 5,001 ms → one onRecover; further checks → no repeats; a beat then another stall → a second episode fires again.
- `WD-02` Suspended → no freeze fires however long; unsuspending resets the clocks (no instant false freeze).
- `WD-03` Global error capture records thrown errors and rejected promises.
- `WD-04` (e2e) With the test hook, `__TC_TEST__.freezeSim(6000)` blocks sim beats; the recovery screen becomes visible within 7 s and its three buttons are present.

## 6. UI shell (`src/ui/`)

Plain DOM + CSS, no framework. Minimal styling: dark background `#090D16`, readable text ≥ 12px, buttons ≥ 44×44 px.

  results, credits, bugReport, recovery`.

  and the buttons listed below. Overlay screens (`pause`, `objectives`, `help`, `recovery`, `bugReport`) stack on top of

- **Control inventory.** Every button is created through `button(id, label, onClick)` which registers a stable

  The Android back button and the Escape key both call `router.back()` (pause overlay opens if in `inGame`).

**Acceptance**

- `UI-02` Overlay stacking and `back()` order: inGame → pause → settings? (settings from pause is an overlay too) → back → back returns to inGame.
- `UI-03` 20 rapid `go('settings')` → one settings DOM root.
- `UI-04` A file `tests/controls.inventory.json` lists every control id that tests cover; a test mounts every screen, reads `ControlInventory.all()` and FAILS if any registered control id is missing from that file (so new buttons can't slip through untested). - `UI-05` (e2e, phone landscape 915×412, tablet 1280×800, desktop 1920×1080) Navigate title → skirmishSetup → loading → inGame → pause → resume; Escape opens pause; every button on every reached screen is ≥ 44×44 CSS px and no two visible buttons overlap.

## 9. Traceability, lint, CI
