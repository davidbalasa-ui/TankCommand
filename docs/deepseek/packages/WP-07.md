# Work package WP-07: enemy AI and AI-vs-AI testing

Adds the SOR "Enemy AI" section on top of WP-04 to WP-06. The AI plays by exactly the player's rules.

## 1. Structure (src/ai/, not inside src/sim)

- `src/ai` is deterministic and headless like the sim (same lint restrictions: no DOM, three, Math.random,
  Date.now). It reads **only** `perceivedUnits(world, side)` plus its own side's state (resources,
  queue, research, own units), and outputs **commands** through the same validated command channel as
  the player. It never writes world state. A lint rule or test proves `src/ai` doesn't import world
  internals beyond the perception API and command types.
- Randomness from its own seeded Rng stored in AI state (saved with the match).
- Runs on the sim tick: strategic layer every 40 ticks (placeholder), tactical layer every 2 ticks.

## 2. Behaviour

Strategic layer:
- Keep miners and tugs working; replace lost ones; spread miners across deposits; claim metal deposits.
- Spend: keep a reserve, research along the tree, buy a mixed army (ratio in data per difficulty).
- Build turrets near pads and along the routes from deposits to pads; build a radar tower.
- Scout with a cheap unit until the enemy pad is found; remember last-known enemy structures.
- Assemble an attack group when army value passes a threshold (data); pick a target: exposed miners /
  tugs, radar, then pads. Retreat the group if it loses most of its value.

Tactical layer:
- Focus fire on the weakest enemy in range; keep range advantage when the enemy is shorter-ranged;
  pull back badly damaged units towards a repair vehicle or pad; defend workers under attack.

Difficulty (setting per AI side): **easy** (slower reaction, smaller army threshold, no focus fire),
**normal**, **hard** (faster reaction, better build ratios). No resource bonus at any level.

## 3. Hook-up

- Skirmish setup from WP-04 gets an AI for the enemy side (difficulty normal), and supports AI-vs-AI
  for tests.
- The player can watch an AI-vs-AI match from a debug route in test builds only.

## 4. Test harness

- `npm run ai:soak` (env `MATCHES`, `SEED`): a Vitest file under `tests/soak/`, excluded from the default
  `npm test` run and run through its own `vitest.soak.config.ts`. It runs N AI-vs-AI matches across all
  maps and difficulties and prints per-match winner, duration and any stuck units. Not part of CI.
- A Vitest suite runs **10** AI-vs-AI matches (fixed seeds) within the CI time budget.

## 5. Requirement IDs

| ID | Requirement |
| --- | --- |
| AI-01 | AI issues only validated commands through the command channel; it can't create units, resources or vision (test: a sim with a hostile command stream from the AI module never changes state outside command rules). |
| AI-02 | AI decisions use only perceived data: moving a hidden enemy unit (outside its vision and sensors) never changes the AI's command output. |
| AI-03 | AI spending never exceeds its income plus starting resources over a whole match. |
| AI-04 | Every one of 10 fixed-seed AI-vs-AI matches ends with a winner before 45 game minutes (placeholder). |
| AI-05 | An AI side with no pads and no fighting units is declared eliminated. |
| AI-06 | Against an idle player with a pad and two tanks, the normal AI destroys the player's pad within 20 game minutes (placeholder). |
| AI-07 | Hard beats easy in at least 8 of 10 fixed-seed matches. |
| AI-08 | No unit stays stuck longer than the re-plan time in any of the 10 matches. |
| DET-05 | AI-vs-AI matches are deterministic: same seed, same hash; save/load mid-match keeps the hash. |
