# Work package WP-10: game shell — pause, speed, saves, settings, audio, bug report

Adds the SOR "Game options, saving, pause and speed" and "Audio and feedback" sections, and fixes the
open items from the WP-01 review (`docs/deepseek/REVIEW.md` is summarised below).

## 1. Pause and speed

- Pause stops the simulation completely; no orders while paused. Auto-pause when the app goes to the
  background (Capacitor `appStateChange` / `visibilitychange`), and on the Android back button (opens the
  pause menu; back again from the pause menu resumes).
- Game speed slow / normal / fast (0.5×, 1×, 2×, placeholders) in single player, from the pause menu
  and a top-bar button.

## 2. Saves

- Manual save and load anywhere in single player (5 slots), autosave every N minutes (data) and when
  backgrounded. Loading restores the match exactly (hash equal to the saved hash).
- On app start, offer "Resume last game" if an autosave exists.
- Quit mid-mission asks for confirmation and offers to save.
- Fix from WP-01 review: the autosave rotation cursor must survive relaunch (newest autosave is never
  overwritten first). `SaveManager.load` returns a typed result (`ok` / `corrupt` / `incompatible` /
  `missing`) instead of throwing; the UI shows a clear message for each.
- Saves go through Capacitor Preferences/Filesystem on native and browser storage on web (the existing
  kv layer); web build gets Export / Import save file in Settings. Handle storage-full with a message.

## 3. Settings screen (phone first, every control ≥ 44 px)

Master, music, effects volume; graphics quality (low / medium / high / auto, wired to the existing
quality system); show health bars (damaged / always); edge-scroll on/off and speed; camera
sensitivity; key rebinding (desktop); left/right-handed layout (from WP-03); text size (normal /
large); colour-blind faction colours; haptics on/off. All persist.

## 4. Audio (src/audio/)

- Web Audio, all sounds **generated in code** (oscillators and noise; no audio files): selection ack,
  order ack (a few variants, not repeating the same one twice in a row), per-weapon-type shot, explosion
  scaled by size, drop beam, mining, delivery, pack/deploy, aircraft launch/land, alert tones.
- Simple generated music loop per faction (calm and combat variants, crossfade on combat).
- Volume settings apply live. Audio starts only after the first user gesture (browser rule).
- Haptics through Capacitor Haptics on selection, orders and alerts when enabled (no-op on web).

## 5. Alerts

- Alert system (stubbed in WP-03) fully wired: under attack (with location), unit lost, structure lost,
  pad lost, deposit empty, research done, drop arrived, objective updated, not enough resources. Toast
  with sound; tapping it jumps the camera there; Space jumps to the latest. Rate-limited so a battle
  doesn't spam.

## 6. Bug report screen

- From the pause menu: text box, include-save checkbox, auto-attached device info, app version, last
  freeze report and last 200 log lines. **No network call yet**: write the report to a file / download it
  and show "Saved". The endpoint comes later.
