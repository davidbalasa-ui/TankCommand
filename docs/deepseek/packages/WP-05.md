# Work package WP-05: structures, research, upgrades and repair

Adds the SOR sections "Structures, placement, pack and relocate", "Research, tech levels and per-unit
upgrades", and repair from "Combat model". Builds on WP-04's drops and kits. All numbers are data
placeholders.

## 1. Structures (src/sim/structures.ts)

- New structure rows (both factions, placeholder copies): **Gun Turret** (fixed gun battery),
  **Radar Tower** (sensor range only matters from WP-06; store the value now), **Research Lab**.
- **Placement rules** for every kit: clear of units, structures, rubble and deposits (except metal
  station on metal), slope under a data threshold across the footprint, fully inside the map, and on
  ground the side has explored (until fog lands in WP-06, "explored" = anywhere). The sim returns a
  reason code; the ghost shows it as text ("Too steep", "Blocked", "Outside map").
- **Pack and relocate**: turrets and miners can `pack` (takes time from data, unit is vulnerable and
  can't fire), then move like a slow vehicle, then `deploy` at a valid spot (same placement rules).
  A packed turret keeps its upgrades and hit points.
- **Dismantle**: any own structure can be dismantled for a refund percentage (data, placeholder 70%) of
  its full cost, paid when dismantling finishes; nothing is paid if it dies first.
- **Damage states**: light / heavy / critical visuals at hp thresholds (renderer: smoke placeholder,
  tint). On death, rubble that blocks placement for a set time.
- Turrets auto-engage like units (reuse the combat system), with a turret turn rate.

## 2. Research (src/sim/research.ts)

- A research tree in data (`src/data/research.placeholder.json`, zod schema): nodes with id, name,
  metal and ore cost, time, prerequisites, and what they unlock (unit ids, structure ids). Placeholder
  tree: 3 tiers, 6 nodes, unlocking the Scout→Tank chain, Turret, Radar Tower and one upgrade each.
- Research runs at a Research Lab (one node at a time per lab). Cost deducted at start; refused without
  enough resources; cancel refunds in full.
- Locked build-menu items show greyed with "Needs: <node name>". Buying a locked item is refused by the
  sim, not only the UI.

## 3. Per-unit upgrades (src/sim/upgrades.ts)

- Upgrades `fireRate`, `armor`, `stealth` applied to **one** selected vehicle for a cost (data), once each
  per unit, only if researched and listed in that unit's `upgrades`. Effects in data (fire rate
  multiplier, flat armor bonus; stealth flag stored now, its effect lands in WP-06).
- An upgraded unit shows a small badge in the selection panel and a coloured marker on the model.

## 4. Repair

- A **Repair Vehicle** unit (both factions, placeholder) restores hit points to damaged friendly units
  and structures within a radius, at a rate from data, never above max hp. Order "Repair" on a target or
  automatic for anything in range while idle.

## 5. UI (phone first)

- Selection panel for a structure: hp, Pack/Deploy, Dismantle, Research (lab), Upgrade (vehicle) buttons
  on the command bar, each ≥ 44 px and disabled with a reason when not possible.
- A Research sheet (bottom sheet on phone) lists the tree by tier with cost, time, state, and progress.

## 6. Requirement IDs

| ID | Requirement |
| --- | --- |
| STR-01 | Placement is refused with the right reason for each case: blocked, too steep, outside the map, on rubble, metal station off a deposit. |
| STR-02 | Pack, move and deploy works for turrets and miners and keeps hp and upgrades; packed turrets can't fire. |
| STR-03 | Dismantle refunds exactly the data percentage on completion and nothing if destroyed first. |
| STR-04 | Structures show damage states and leave rubble that blocks placement for the set time. |
| STR-05 | Turrets auto-engage enemies in range using the combat model. |
| RES-01 | A locked unit or structure can't be bought (sim refuses, UI shows the requirement). |
| RES-02 | Research can't start without enough resources, deducts at start, refunds on cancel, unlocks on completion. |
| UPG-01 | An upgrade changes only the chosen vehicle, can be bought once per type, and needs its research. |
| UPG-02 | Fire-rate and armor upgrades change combat results by exactly their data values. |
| REP-01 | Repair vehicles heal friendly units and structures in range up to max hp, never above. |
| DET-03 | Structures, research and upgrades survive save/load with an identical hash. |
